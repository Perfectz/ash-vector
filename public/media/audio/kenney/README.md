# Kenney Sci-Fi Sounds

Source: Kenney Sci-Fi Sounds 1.0, supplied by the user from https://kenney.nl/assets/sci-fi-sounds.
Creator: Kenney, https://kenney.nl. Licensed CC0; original License.txt is included.

21 selected source OGG recordings were converted to mono 44.1 kHz / 96 kbps MP3 for broad browser decoding support. Long sources are trimmed to their first 2.5 seconds; the game uses shorter envelopes where appropriate. Basenames preserve the original source filenames.

The game layers recordings with original synthesized bass and energy sounds. It adds playback-rate variation, stereo positioning, music ducking and a compressor. No attribution is required by CC0, but we gratefully credit Kenney.
